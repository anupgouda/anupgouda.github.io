Machine learning · 2025

Healthcare Fraud Analytics Platform

An end-to-end system that scores Medicare providers for fraud-investigation risk using more than 550K real inpatient, outpatient and beneficiary records.

  • Random Forest trained and tuned on 16 provider-level features, served through a FastAPI prediction service with a Streamlit dashboard.
  • SHAP explanations ship with every prediction, so investigators see which features drove a score. The score is a risk signal for human review and makes no automated fraud determination.
  • Investigation workflow (status, priority, assignment, notes) modeled on a 3-table PostgreSQL schema.
  • 30 automated tests with pytest across the model, API and repository layers.
